# 🍻 Barzinho 3D com R3F

Um mini jogo em primeira pessoa onde você pode explorar um barzinho 3D e curtir aquele som de bar! Feito com [React Three Fiber (R3F)](https://docs.pmnd.rs/react-three-fiber), o projeto oferece uma experiência imersiva simples e divertida.

## 🎮 Como jogar

- Use as teclas **W, A, S, D** para andar pelo bar.
- Aperte os números **1 a 4** no teclado para trocar as músicas.

## 🎵 Trilha sonora

1. **Barões da Pisadinha** – Já Que Me Ensinou a Beber (versão abafada)  
2. **Barões da Pisadinha** – Já Que Me Ensinou a Beber (versão normal)  
3. **João Gomes** – A Noite (versão abafada)  
4. **João Gomes** – A Noite (versão normal)
